1 · Install

  1. Windows: run the .exe file. If Windows shows a warning: More info › Run anyway.
  2. Mac: open the .dmg, drag the application into Applications, then on first launch: right-click › Open.
  3. Language: choose Français, English or Hausa at the top of the activation screen (or in Settings).

2 · Try, then activate

  1. Click Try … for 14 days (START for the single-activity software, GESTION for TAMTUI SAHEL 360).
  2. For the full version: Copy the code of the computer and send it to your TAMTUI supplier.
  3. Import the licence file you receive: the software is permanently activated.

Recommended configuration

  • Windows 10 or 11 (64-bit) — Windows 7 and 8 are not supported
  • macOS 11 or later (Intel or Apple)
  • 4 GB of memory, 500 MB of disk space
  • Screen of at least 1280 × 800
  • Internet only for weather and updates

🔌 Windows computer without Internet?

Windows 11 and updated Windows 10 are ready. On a Windows 10 that has never been updated and has no Internet, installation needs a Microsoft component (WebView2): bring it with the software on a USB stick.

  1. Where there is Internet, download the software's Windows installer and the component opposite, then copy both onto a USB stick.
  2. On the computer without Internet, first run the Microsoft component (once per computer, for all TAMTUI software).
  3. Then run the TAMTUI installer: it installs without Internet.
