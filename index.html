1 · Installer

  1. Windows : lancez le fichier .exe. Si Windows affiche un avertissement : Informations complémentaires › Exécuter quand même.
  2. Mac : ouvrez le .dmg, glissez l'application dans Applications, puis au premier lancement : clic droit › Ouvrir.

2 · Essayer puis activer

  1. Cliquez sur Essayer START pendant 14 jours.
  2. Pour la version complète : Copier le code de l'ordinateur et envoyez-le à votre fournisseur TAMTUI.
  3. Importez le fichier de licence reçu : le logiciel est activé définitivement.

Configuration conseillée

  • Windows 10 ou 11, ou macOS 11 et plus récent (Intel ou Apple)
  • 4 Go de mémoire, 500 Mo d'espace disque
  • Écran de 1280 × 800 au minimum
  • Internet uniquement pour la météo et les mises à jour
Déjà client ? Votre logiciel se met à jour tout seul : au démarrage, il propose les nouvelles versions (« Nouvelle version disponible › Installer maintenant »). Vos données et votre licence sont conservées, et une sauvegarde est faite avant chaque mise à jour.
