1 · Installer

  1. Windows : lancez le fichier .exe. Si Windows affiche un avertissement : Informations complémentaires › Exécuter quand même.
  2. Mac : ouvrez le .dmg, glissez l'application dans Applications, puis au premier lancement : clic droit › Ouvrir.
  3. Langue : choisissez Français, English ou Hausa en haut de l'écran d'activation (ou dans Paramètres).

2 · Essayer puis activer

  1. Cliquez sur Essayer … pendant 14 jours (START pour les logiciels métier, GESTION pour TAMTUI SAHEL 360).
  2. Pour la version complète : Copier le code de l'ordinateur et envoyez-le à votre fournisseur TAMTUI.
  3. Importez le fichier de licence reçu : le logiciel est activé définitivement.

Configuration conseillée

  • Windows 10 ou 11 (64 bits) — Windows 7 et 8 ne sont pas pris en charge
  • macOS 11 et plus récent (Intel ou Apple)
  • 4 Go de mémoire, 500 Mo d'espace disque
  • Écran de 1280 × 800 au minimum
  • Internet uniquement pour la météo et les mises à jour

🔌 Ordinateur Windows sans Internet ?

Windows 11 et les Windows 10 à jour sont prêts. Sur un Windows 10 jamais mis à jour et sans Internet, l'installation a besoin d'un composant de Microsoft (WebView2) : apportez-le avec le logiciel sur une clé USB.

  1. Là où il y a Internet, téléchargez l'installateur Windows du logiciel et le composant ci-contre, puis copiez les deux sur une clé USB.
  2. Sur l'ordinateur sans Internet, lancez d'abord le composant Microsoft (une seule fois par ordinateur, pour tous les logiciels TAMTUI).
  3. Lancez ensuite l'installateur TAMTUI : il s'installe sans Internet.
